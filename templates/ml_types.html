Tipos de Machine Learning

Los algoritmos de ML se clasifican segun la presencia de etiquetas en los datos y la forma de retroalimentacion.

🏷️

Aprendizaje Supervisado

El modelo se entrena con datos etiquetados: cada ejemplo incluye su respuesta o valor objetivo correcto.

  • Clasificacion: Predice categorias discretas (spam/no spam, diagnostico medico).
  • Regresion: Predice valores numericos continuos (precios de casas, temperatura).
  • Supervision directa: Calcula el error entre la prediccion y la etiqueta real.
Regresion Lineal Random Forest SVM Redes Neuronales
🔍

Aprendizaje No Supervisado

Los datos no tienen etiquetas. El algoritmo descubre patrones ocultos, agrupaciones o estructuras intrinsecas.

  • Clustering: Segmentacion de clientes, agrupamiento de documentos.
  • Reduccion de Dimensionalidad: Comprimir variables manteniendo varianza (PCA).
  • Deteccion de Anomalias: Fraudes bancarios, fallas industriales.
K-Means DBSCAN PCA Autoencoders
🎮

Aprendizaje por Refuerzo

Un agente aprende a tomar decisiones optimas interactuando con un entorno mediante recompensas y castigos.

  • Exploracion vs. Explotacion: Descubrir nuevas estrategias o aprovechar las conocidas.
  • Sin etiquetas directas: Se aprende por ensayo y error.
  • Aplicaciones: Conduccion autonoma, videojuegos, robotica.
Q-Learning DQN PPO Policy Gradient
