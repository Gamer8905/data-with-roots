Types of Machine Learning

ML algorithms are classified according to the presence of labels in the data and the type of feedback used.

🏷️

Supervised Learning

The model is trained on labeled data: each example includes its correct answer or target value.

  • Classification: Predicts discrete categories (spam/not spam, medical diagnosis).
  • Regression: Predicts continuous numerical values (house prices, temperature).
  • Direct supervision: Computes the error between the prediction and the actual label.
Linear Regression Random Forest SVM Neural Networks
🔍

Unsupervised Learning

The data has no labels. The algorithm discovers hidden patterns, groupings, or intrinsic structures.

  • Clustering: Customer segmentation, document grouping.
  • Dimensionality Reduction: Compressing variables while preserving variance (PCA).
  • Anomaly Detection: Bank fraud, industrial failures.
K-Means DBSCAN PCA Autoencoders
🎮

Reinforcement Learning

An agent learns to make optimal decisions by interacting with an environment through rewards and penalties.

  • Exploration vs. Exploitation: Discovering new strategies or leveraging known ones.
  • No direct labels: Learning happens through trial and error.
  • Applications: Autonomous driving, video games, robotics.
Q-Learning DQN PPO Policy Gradient
