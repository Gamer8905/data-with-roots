Machine Learning Types

ML algorithms are classified based on the presence of labels in the data and the form of feedback.

🏷️

Supervised Learning

The model is trained with labeled data: each example includes its correct answer or target value.

  • Classification: Predicts discrete categories (spam/no spam, medical diagnosis).
  • Regression: Predicts continuous numeric values (house prices, temperature).
  • Direct supervision: Calculates the error between the prediction and the actual label.
Linear Regression Random Forest SVM Neural Networks
🔍

Unsupervised Learning

The data has no labels. The algorithm discovers hidden patterns, groupings or intrinsic structures.

  • Clustering: Customer segmentation, document grouping.
  • Dimensionality Reduction: Compress variables while maintaining variance (PCA).
  • Anomaly Detection: Bank fraud, industrial failures.
K-Means DBSCAN PCA Autoencoders
🎮

Reinforcement Learning

An agent learns to make optimal decisions by interacting with an environment through rewards and punishments.

  • Exploration vs. Exploitation: Discover new strategies or exploit known ones.
  • No direct labels: Learning is through trial and error.
  • Applications: Autonomous driving, video games, robotics.
Q-Learning DQN PPO Policy Gradient
