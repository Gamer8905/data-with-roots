Estimar Tiempo de Entrega segun Distancia

Modelo de Regresion Lineal Simple implementado con scikit-learn, numpy, pandas y matplotlib.

# 1. Contexto del Problema

Problema a Resolver

Que problema se esta resolviendo?

Las empresas de logistica y domicilios necesitan estimar con precision el tiempo que tardara un envio para planificar rutas, asignar repartidores y mejorar la experiencia del cliente.

El fenomeno que se analiza es la relacion entre la distancia que recorre un paquete desde el punto de origen hasta el destino, y el tiempo total que toma完成 el delivery.

Los datos representan 600 envios historicos con su distancia recorrida y tiempo real de entrega registrado. Se aplica Regresion Lineal Simple para:

  • Descubrir la relacion matematica entre distancia y tiempo.
  • Predigir el tiempo estimado de entrega para nuevas distancias.
  • Mejorar la planificacion logistica con datos reales.
# 2. Variables del Modelo

Variables

X

Variable Independiente (X)

Distancia recorrida

La distancia en kilometros desde el punto de origen hasta el destino del envio. Es el valor de entrada que el usuario proporciona para hacer la prediccion.

Unidad: kilometros (km)

Y

Variable Dependiente (Y)

Tiempo de entrega

El tiempo total en minutos que tarda el envio en completarse. Es el valor que el modelo intenta predecir.

Unidad: minutos (min)
