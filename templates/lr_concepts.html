Regresion Lineal - Conceptos

Fundamentos necesarios para comprender el algoritmo de Regresion Lineal Simple.

# Definicion

Que es Regresion Lineal?

La Regresion Lineal es un algoritmo de Machine Learning supervisado que modela la relacion entre una variable independiente (X) y una variable dependiente (Y) ajustando una linea recta que mejor represente los datos.

Formula: Y = mX + b donde m es la pendiente (slope) y b es el intercepto (bias).

El objetivo es encontrar los valores optimos de m y b que minimicen la diferencia entre los valores reales y los predichos.

# Problemas

Que problemas resuelve?

Prediccion de Valores

Estimar el precio de una vivienda, el salario esperado, o el tiempo de entrega basandose en una variable de entrada.

Analisis de Tendencias

Identificar la direccion y fuerza de la relacion entre dos variables: a mayor distancia, mayor tiempo.

Extrapolacion

Hacer estimaciones para valores fuera del rango observado (con precaucion).

# Variables

Variables Independiente y Dependiente

X

Variable Independiente (X)

Es la variable de entrada o predictor. Es el valor que el usuario proporciona al modelo. Se encuentra en el eje horizontal (eje X) del grafico.

Ejemplo: Distancia en kilometros.

Y

Variable Dependiente (Y)

Es la variable de salida o objetivo. Es el valor que el modelo intenta predecir. Se encuentra en el eje vertical (eje Y) del grafico.

Ejemplo: Tiempo de entrega en minutos.

# Relacion

Relacion entre Variables y Linea de Regresion

La linea de regresion representa la mejor aproximacion lineal de los datos. Cada punto en el grafico de dispersion (scatter plot) representa un registro del dataset.

  • Los puntos se dispersan alrededor de la linea.
  • La linea minimiza la suma de los errores cuadraticos (MSE).
  • Si la pendiente es positiva, a mayor X, mayor Y.
  • Si la pendiente es negativa, a mayor X, menor Y.
Pendiente (m): Indica cuanto cambia Y por cada unidad que aumenta X.
Intercepto (b): Indica el valor de Y cuando X = 0.
# Prediccion

Prediccion con Regresion Lineal

Una vez entrenado el modelo (ajustada la linea), se puede predecir el valor de Y para cualquier valor de X nuevo:

# Ejemplo de prediccion
distancia_nueva = 50 # km
tiempo_predicho = modelo.predict([[distancia_nueva]])
# Resultado: ~27.5 minutos

El modelo simplemente evalua la ecuacion Y = mX + b con el nuevo valor de X.
