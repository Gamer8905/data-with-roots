Linear Regression - Concepts

Fundamentals needed to understand the Simple Linear Regression algorithm.

# Definition

What is Linear Regression?

Linear Regression is a supervised Machine Learning algorithm that models the relationship between an independent variable (X) and a dependent variable (Y) by fitting a straight line that best represents the data.

Formula: Y = mX + b where m is the slope and b is the intercept (bias).

The goal is to find the optimal values of m and b that minimize the difference between the actual and predicted values.

# Problems

What problems does it solve?

Value Prediction

Estimate the price of a house, expected salary, or delivery time based on an input variable.

Trend Analysis

Identify the direction and strength of the relationship between two variables: the greater the distance, the greater the time.

Extrapolation

Make estimates for values outside the observed range (with caution).

# Variables

Independent and Dependent Variables

X

Independent Variable (X)

It is the input or predictor variable. It is the value the user provides to the model. It is located on the horizontal axis (X axis) of the chart.

Example: Distance in kilometers.

Y

Dependent Variable (Y)

It is the output or target variable. It is the value the model tries to predict. It is located on the vertical axis (Y axis) of the chart.

Example: Delivery time in minutes.

# Relationship

Relationship between Variables and Regression Line

The regression line represents the best linear approximation of the data. Each point in the scatter plot represents a record in the dataset.

  • The points are scattered around the line.
  • The line minimizes the sum of squared errors (MSE).
  • If the slope is positive, the greater the X, the greater the Y.
  • If the slope is negative, the greater the X, the smaller the Y.
Slope (m): Indicates how much Y changes for each unit that X increases.
Intercept (b): Indicates the value of Y when X = 0.
# Prediction

Prediction with Linear Regression

Once the model is trained (the line is fitted), the value of Y can be predicted for any new value of X:

# Prediction example
new_distance = 50 # km
predicted_time = model.predict([[new_distance]])
# Result: ~27.5 minutes

The model simply evaluates the equation Y = mX + b with the new value of X.

# Simple Example

Intuitive Example

Imagine you want to estimate how long a delivery takes. You have data from 600 previous shipments with the distance and actual time.

Step 1

Collect historical data on distance and delivery time.

Step 2

Train the model with scikit-learn to find the best line.

Step 3

Enter a new distance and get the time prediction.

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_distance, Y_time) # Train
prediction = model.predict([[80]]) # Predict for 80 km
# Result: ~41 minutes
